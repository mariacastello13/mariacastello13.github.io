# María Castelló Pons — Personal Website

Static personal website built with HTML and CSS. Includes a profile photograph, research and professional experience, selected publications, and contact details.

## Publish with GitHub Pages
1. Create a public GitHub repository named `mariacastellopons.github.io`.
2. Upload the contents of this folder (not the folder itself) to the repository root.
3. In repository Settings → Pages, select deployment from the `main` branch and `/ (root)`.
4. Wait for GitHub Pages to publish the site at `https://mariacastellopons.github.io/`.

Review all personal details and publication records before publishing.
